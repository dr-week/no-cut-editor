# OpenCut Premiere Pro Keyboard Shortcuts Reference

This guide lists the integrated **Adobe Premiere Pro keyboard shortcuts** active in OpenCut:

---

## Active Keyboard Shortbinds

| Key | Premiere Pro Action | OpenCut Behavior |
| --- | --- | --- |
| **`Space`** | **Play / Pause** | Toggles video playback on the viewport canvas. |
| **`C`** | **Razor Tool (Split)** | Triggers clip splitting at the active playhead position. |
| **`V`** | **Selection Tool** | Switches cursor to standard element selection mode. |
| **`Shift + Delete`** | **Ripple Delete** | Deletes the selected clip and closes the timeline gap. |
| **`I`** | **Mark In** | Sets the timeline in-point marker. |
| **`O`** | **Mark Out** | Sets the timeline out-point marker. |

---

## Toast Notification System
Pressing any shortcut key instantly triggers a CapCut-style active shortcut toast notice in the top bar!
