## 5. UI/value design goals

- each preset should have category, label, keywords, and kind
- each preset should be searchable by tag and label
- preset metadata should be the single source of truth
- preset browser should support kind filters and category filters
- custom presets can later be imported/exported via JSON

## 6. Why this matters

More presets increase perceived product value and reduce user hesitation. At the same time, a metadata-first structure allows new presets to be added without rewriting UI logic or scattered custom checks.
